# среда. — HTML demo

Мобильная демо-версия интерьерной платформы «среда.».

## Что работает
- Pinterest-подобная лента товаров
- категории
- карточки товаров
- выбор отделки и размеров
- размеры кроватей 140×200 / 160×200 / 180×200 / 200×200 / индивидуальное производство
- избранное с сохранением в localStorage
- поиск и демо-поиск по изображению
- добавление в спецификацию
- запрос расчёта с переходом в чат
- сообщения
- профили Дизайнер / Поставщик

## GitHub Pages
1. Загрузите все файлы и папки из корня проекта в репозиторий.
2. Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main, folder: / (root).
5. Save.

Главный файл: `index.html`.
